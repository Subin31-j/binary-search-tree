#  Binary Search Tree (BST) Implementation in Java

## 📌 Overview
This project implements a **Binary Search Tree (BST)** in Java.  
It demonstrates fundamental **Data Structures** concepts along with **recursion**, **object-oriented programming**, and **tree traversal algorithms**.

The program supports core BST operations such as insertion, searching, deletion, and different traversal techniques.

---


## Features Implemented

### BST Operations
- Insert a node
- Search for a value
- Delete a node (handles all cases)
  - Leaf node
  - Node with one child
  - Node with two children

### 🔁 Tree Traversals
- **In-order Traversal** (Left → Root → Right)
- **Pre-order Traversal** (Root → Left → Right)
- **Post-order Traversal** (Left → Right → Root)

---

## 🧩 Program Structure

- `TreeNode` class  
  Represents a node in the BST with:
  - `value`
  - `left` child
  - `right` child

- `BinarySearchTree` class  
  Contains logic for:
  - Insert
  - Search
  - Delete
  - Traversals
